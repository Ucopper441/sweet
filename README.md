# 💕 Sweet - A Romantic Website

A beautiful, interactive romantic website featuring love letters, special messages, animated effects, and background music.

## ✨ Features

- 💌 **Love Letter**: A heartfelt message from the heart
- 💬 **Interactive Messages**: Click through special messages with emojis
- 🎨 **Floating Hearts**: Click anywhere on the canvas to create floating hearts
- 🎵 **Background Music**: Toggle music player
- ⭐ **Animated Background**: Twinkling stars
- 📱 **Responsive Design**: Works beautifully on all devices
- 🎯 **Interactive Elements**: Hover effects, smooth animations, and transitions

## 🚀 How to Use

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Click the music note icon to toggle background music
4. Click "Open Letter" to read the love letter
5. Click on message cards to see them animate
6. Click anywhere on the floating hearts canvas to create hearts

## 🎨 Customization

### Edit the Love Letter
Open `index.html` and find the `.letter-content` section to edit the message.

### Add Your Photos
Replace the gradient placeholders in the gallery section with your own photos by changing the `.gallery-item` elements to use `<img>` tags:

```html
<div class="gallery">
    <img src="path/to/photo1.jpg" alt="Our moment" class="gallery-item">
    <img src="path/to/photo2.jpg" alt="Our moment" class="gallery-item">
    <!-- Add more photos -->
</div>
